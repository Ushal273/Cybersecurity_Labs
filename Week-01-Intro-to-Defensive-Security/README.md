## 🧠 Key Skills & Concepts Learned

### 1. Blue Teaming Fundamentals
* **Defensive Mindset:** Learned how defensive security teams protect organizational assets, monitor internal networks, and maintain infrastructure resilience against active threats.
* **Security Operations Center (SOC):** Explored the critical role a SOC plays as a centralized unit dealing with high-volume security issues on an organizational level.

### 2. SOC Analyst Responsibilities
* **Alert Triage:** Understood how to monitor real-time security alerts and distinguish between benign network anomalies and actual malicious activity.
* **Incident Investigation & Response:** Practiced identifying the source of an attack (such as unauthorized access or standard brute-force patterns) using available logs.
* **Remediation:** Followed standard operating procedures to mitigate threats, including isolating compromised endpoints and blocking malicious actor IP addresses.
* **False Positive Management:** Recognized the importance of accurately identifying and closing out false alarms to maintain operational efficiency and clear log data.

### 3. Proactive Security Frameworks
* Connects directly to core defensive frameworks such as the **ACSC Essential Eight**, specifically emphasizing the value of robust continuous monitoring, network segmentation, and restricted administrative privileges to blunt the impact of an intrusion.
